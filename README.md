# labs_ppois
# Лабораторные работы по ППОИС

Репозиторий для лабораторных работ по курсу ППОИС на C++.

## Лабораторная работа №1 (`lab1`)

Варианты: **1.1 Вектор** и **1.7.1 / 1.7.2 Вещественная матрица**.

Что внутри:
- `Vector3D` — вектор в 3D по точкам начала и конца: длина, `+`/`-`, векторное произведение, умножение и деление на число, косинус угла, сравнения по длине, ввод/вывод в поток.
- `RealMatrix` — вещественная матрица произвольного размера (динамический буфер):
  - из 1.7.1: `resize`, загрузка из файла, подматрица, проверки типа (квадратная, нулевая, диагональная, единичная, симметричная, треугольные), транспонирование;
  - из 1.7.2: арифметика с матрицами и числами, `++`/`--`, возведение в степень, определитель (методом Гаусса) и норма.
- `CliMenu` — консольное меню, отдельно от логики классов.
- `tests/` — юнит-тесты на Catch2 (скачивается сам через CMake).

### Сборка и запуск

Нужны компилятор с поддержкой C++20 и CMake >= 3.20.

```bash
cmake -S lab1 -B build -DCMAKE_BUILD_TYPE=Debug -DENABLE_COVERAGE=ON
cmake --build build --parallel
./build/lab1_cli
